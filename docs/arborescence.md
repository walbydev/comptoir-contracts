## The mod itself — `[plan]`

The archive that ships has exactly this shape; the folder name inside the zip is
`comptoir-contracts_<version>/`.

```
comptoir-contracts_0.1.0/
├── info.json                      name, version, factorio_version "2.1", no hard dependency on Space Age
├── data.lua                       requires the prototype files
├── data/
│   ├── counter.lua                the counter: container clone, min-distance, power draw
│   ├── elevator.lua               the shaft and the car's three states
│   ├── item.lua                   the mod's own items, if any (v1: none expected)
│   └── technology.lua             the early red/green technology that unlocks the counter
├── control.lua                    event wiring only; no logic of its own
├── scripts/
│   ├── ledger.lua                 accounts, hold/release/forfeit, conservation assert
│   ├── companies.lua              creation, character, seeded LCG, tier resolution
│   ├── contracts.lua              generation, acceptance, delivery, expiry
│   ├── elevator.lua               the state machine (down / rising / away / descending)
│   ├── counter.lua                buy and sell, spread, clamping
│   ├── gui/                       the window: frame, header, contracts tab, counter tab
│   └── migrate.lua                storage.version and the migration chain
├── data/prices.lua                GENERATED by tools/cost_table.py — never edited by hand
├── locale/
│   ├── en/strings.cfg
│   └── fr/strings.cfg
└── thumbnail.png
```

Rules the tree encodes, so they cannot be forgotten:

- **`data/prices.lua` is generated**, and the generator lives in the repo. A number that came from the
  game's own recipes can be regenerated and reviewed in a diff.
- **`control.lua` has no logic**, only `script.on_*` wiring. It is the file most likely to be read by
  someone else.
- **`scripts/gui/` is a directory**, because the window is the one place where a single file becomes
  unreadable first.
- **`data/` and `scripts/` never mix**: a prototype error is a load failure for everyone, a script error
  is a runtime failure for one save. Keeping them apart keeps the two failure modes apart.
- The **test mod is not here**: it lives beside the project, in `test-mod/comptoir-test_0.0.1/`, and
  `make package` copies an explicit file list — the test mod is not on it.
