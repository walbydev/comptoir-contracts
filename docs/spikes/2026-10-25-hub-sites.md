# Spike 2026-10-25 — can a building be restricted to a dedicated zone?

**Question.** The requester proposed building hubs only on dedicated zones, "like ore patches"
(ADR `0021`). Does Factorio 2.1 offer a native way to restrict a building to such a zone?

**Environment.** Factorio headless `2.1.23 build 87750`, mods `base` + `space-age` (DLC present on this
install). Spike mod: `spike/hub-site/hub-site-spike_0.0.1/`.

```
/opt/data/.local/opt/factorio/bin/x64/factorio \
  --mod-directory spike/hub-site --create /tmp/spike-out/test.zip
```

## Results (measured, not read)

| Path | `can_place_entity{build_check_type = manual}` on bare ground | Verdict |
|---|---|---|
| `container` + `resource_categories = {"hub-site"}` | **`true`** | field accepted by the data stage, **ignored at runtime** |
| `mining-drill` + `resource_categories = {"hub-site"}` | **`false`** | **enforced natively** (the pumpjack / crude-oil mechanism) |
| custom `tile` + `tile_buildability_rules` | not testable | tile layers are a fixed engine enum (`ground_tile`, `water_tile`) — base data uses only those |

Two traps found on the way:

- `build_check_type` is a **number** (`defines.build_check_type.<name>`), not a string. The **default
  is `always`, which skips placement rules entirely** — a test that omits it will report "placeable"
  for a pumpjack on grass.
- `create_entity` bypasses the restriction too (`build_check_type = script` → allowed). A mod that
  places a hub by script must check the site itself; the engine will not refuse it.
- An `infinite` resource cannot have `minimum = 0`; the data stage refuses the map.
- A resource `category` must exist as a `resource-category` prototype.

## Why the native mechanism was not taken

It forces the hub to be a `mining-drill`, which brings a mining area, a drilling progress and a
**mining result box** instead of a general inventory. ADR `0016` requires the hub to carry a general
inventory fed by inserters and robots. Native placement would cost the building simplification the
requester had just bought.

## Decision carried into the framing

Script check at build time + a visible, unmineable site patch. Cost is unchanged from the
minimum-distance rule it replaces (`0014` already needed `on_built_entity` + `find_entities_filtered`
+ refund).
