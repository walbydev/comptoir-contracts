# Spec 001 — tasks

- **Status**: ready to execute, 2026-10-25
- **Rule**: a task is done when its **exit check** passes, quoted. "Committed" is not done.

## Lot (a) — the core, playable without a window

| # | Task | Exit check |
|---|---|---|
| **a1** | Repo skeleton: `info.json`, `data.lua`, `control.lua`, `locale/{en,fr}/strings.cfg`, `.gitignore` for `data/prices.lua` **not** ignored (it is generated but committed) | the game loads the mod, `--create` succeeds |
| **a2** | `tools/cost_table.py --lua > data/prices.lua`: the table as Lua data, regenerated by one command | `make prices` produces a diff-free file |
| **a3** | Prototype: the counter (a `container` clone, inventory size, min-distance), item, recipe, technology — **no energy field** (D75) | `--create` succeeds with the mod; the counter is placable after researching the technology |
| **a4** | `storage` v1 + `migrate.lua` skeleton + `on_init` / `on_configuration_changed` no-ops | a save/load cycle keeps `storage.version == 1` |
| **a5** | `ledger.lua`: hold / release / forfeit / debit / credit + `assert_conservation` | unit assertions in the test mod: 9 operations, conserved sum (A3) |
| **a6** | `companies.lua`: creation on build, name, character, tier from `prices`, LCG | placing a counter creates exactly one company with a stable name across reloads |
| **a7** | `contracts.lua` generation: pool = unlocked ∩ tier, weighted pick, quantity from the payout band, deadline incl. the cycle | 1000 generations, never an unlocked recipe (A18), always deadline ≥ cycle (A30) |
| **a8** | `contracts.lua` accept / dispatch / pay / expire, with the reserve | A13 (expiry moves exactly the reserve), A14 (from zero, selling recovers) |
| **a9** | `elevator.lua`: the four states, one flight at a time, resume after load | A29 (only `down` sends); a save mid-flight resumes |
| **a10** | `counter.lua`: buy at `cost × 1.5`, sell at `cost`, always buying, clamped | A15 (buy-then-sell always loses) |
| **a11** | `test-mod/` skeleton + the runner `tools/run_tests.py` + `make test` in both DLC dirs | six green scenarios, exit code 0, output quoted |

**Lot (a) is done when** `make test` is green in both configurations and `make check` reports no Lua
syntax error. No window exists: everything is driven through the remote interface.

## What is not a task, on purpose

Anything parked in `0025`, the travelling elevator car (`0044`), orbital power (`0030`), and "while I'm
here" improvements. An idea that arrives during lot (b) becomes an ADR and a line in the parking list;
it does not become a task.
